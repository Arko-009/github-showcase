# 🎖️ GitHub Profile Badges & Achievements Guide

A complete reference guide for developer achievements on GitHub.

## 1. Quickdraw ⚡
- **Criteria**: Close an issue or pull request within 5 minutes of opening it.
- **Tip**: Perfect for closing quick self-resolved issues.

## 2. Pair Extraordinaire 👯
- **Criteria**: Co-author a commit that gets merged into the default branch via a pull request.
- **Syntax**:
  ```git
  Co-authored-by: Name <username@users.noreply.github.com>
  ```

## 3. YOLO 🤹
- **Criteria**: Merge a pull request without waiting for or requesting code review.

## 4. Pull Shark 🦈
- **Bronze**: 2 merged PRs
- **Silver**: 16 merged PRs
- **Gold**: 128 merged PRs

## 5. Galaxy Brain 🧠
- **Criteria**: Have answers marked as the accepted solution in GitHub Discussions.
